# AdaptixBOF

Forks of TrustedSec's BOF collections with `.axs` scripts added so they can be loaded and run from [Adaptix C2](https://github.com/Adaptix-Framework/AdaptixC2). The `.axs` files are ports of the original Cobalt Strike `.cna` (Aggressor) scripts. The BOF source code is unchanged.

| Folder | Upstream | Adaptix script |
|---|---|---|
| `CS-Situational-Awareness-BOF-master` | [trustedsec/CS-Situational-Awareness-BOF](https://github.com/trustedsec/CS-Situational-Awareness-BOF) | `SA/SA.axs` |
| `CS-Remote-OPs-BOF-main` | [trustedsec/CS-Remote-OPs-BOF](https://github.com/trustedsec/CS-Remote-OPs-BOF) | `Remote/Remote.axs`, `Injection/Injection.axs` |

All credit for the BOFs goes to TrustedSec. Each folder keeps its original LICENSE.
